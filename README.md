# TDE 2 - Código Morse

Trabalho desenvolvido pelas alunas Amanda e Valentina, na disciplina de Resolução de Problemas Estruturados em Computação, do 4º período do curso de Bacharelado em Engenharia de Software.

O programa usa uma árvore binária para codificar e decodificar código Morse (ponto à esquerda e traço à direita) e imprime a árvore no console.

## Como executar

```
javac -encoding UTF-8 *.java
java Main
```

Requer Java 11 ou mais recente.
